# Istanbul scenes

termist shows a hand-drawn Istanbul landmark on the splash screen, the empty grid, the idle screen and
the About page. The colours follow the real time of day, and each scene has a few gentle animations.
This folder is the source of truth for those scenes. The Rust renderer reads these files, and
`tools/scene-preview.py` previews them in a truecolor terminal.

**Style reference: `galata/`, approved.** Every other scene must look like it belongs next to it.

## Files per scene

```
assets/scenes/<name>/
  large.art.txt    the characters: printable ASCII only, at most 96 columns x 26 rows
  large.mask.txt   same shape; one key character per cell, telling what that cell is
  palette.toml     colours for the scene's own keys (and overrides of shared ones), per time of day
  scene.toml       title, horizon key and the list of effects
```

`palettes.toml` (shared) holds the four times of day, `sabah` (06-11), `gunduz` (11-17), `aksam` (17-20,
sunset) and `gece` (20-06), and the keys Galata uses. A scene's `palette.toml` uses the same four tables.
Its keys are merged over the shared ones, so a scene can add keys (e.g. `C` for a column) or recolour
the sky.

The art may be generated by a small builder script (`tools/scenes/build_<name>.py`, see
`build_galata.py`). The `.txt` files are what ships, and hand edits to them are fine.

## Mask keys

- Below the horizon, a cell without its own `bg` sits on the `water` gradient (when the palette has one), not the sky.
- A space in the mask is **sky**: its background is the vertical `sky` gradient, running from the top
  row down to the horizon (the first row that contains `horizon_key`).
- Any other key is looked up in the palette: `K = { fg = "#rrggbb", bg = "#rrggbb" }`. Leave out `bg`
  and the cell sits on the sky gradient (line art). Give it a `bg` and the cell is filled (solid shapes).
  Galata uses outline keys in capitals (`R`, `S`, `H`) and matching fill keys in lower case (`r`, `s`, `h`).
- Shared keys (defined in `palettes.toml`):

| Key | Meaning | Key | Meaning |
|---|---|---|---|
| `R` / `r` | roof or cone, outline / fill | `W` | window, lit after sunset |
| `S` / `s` | stone wall, outline / fill | `G` | quay or ground line |
| `H` / `h` | house wall, outline / fill | `w` | water (painted by the `waves` effect) |
| `D` | dark stone trim | `M` | sun or moon |
| `T` | roof tiles | `V` / `K` / `F` | ferry cabin / hull / chimney |

## Effects (`scene.toml`)

The effect vocabulary is fixed. The Rust renderer implements exactly these, so a scene never ships its
own code. `times = [...]` limits an effect to some palettes; leave it out for always-on.

| Type | Parameters | What it does |
|---|---|---|
| `waves` | `key="w"`, `every=2`, `glints=true`, `glint_density=1.0`, `glint_rows=4` | Water cells get the `water` gradient; the art's `~` pattern scrolls sideways, alternate rows in opposite directions; glints sparkle. Glints per column stay constant however tall the water is (calibrated on 4 rows); `glint_density` scales them |
| `stars` | `count=28` | Twinkling stars in the sky, above the horizon |
| `gulls` | `rows=[4,6,3]`, `color` | Seagulls (`\v/` / `-v-`) fly right to left across sky cells |
| `smoke` | `key="F"`, `drift=-1` | Puffs rise from the top of the `key` cells and drift sideways |
| `twinkle` | `key="W"`, `threshold=0.85`, `off` | Cells of `key` go dark now and then (windows, lamps) |
| `blink` | `key`, `colors=[...]`, `period=20`, `wave=0` | Cells of `key` cycle through colours; `wave>0` makes the cycle travel along x (bridge lights) |
| `sprite` | `art=[...]`, `mask=[...]`, `row`, `speed=0.3`, `direction=1`, `over=" w"`, `smoke_key`, `frames`, `mask_frames`, `frame_every=3`, `twinkle_key`, `twinkle_times`, `twinkle_off` | A multi-line object moves horizontally and wraps around. `'.'` in its mask is transparent, and it is drawn only over scene cells whose key is in `over`, so it passes behind buildings. `smoke_key` cells emit trailing smoke. `frames` (with optional `mask_frames`) gives flip-book animation in place of `art`. `twinkle_key` cells go dark now and then, like windows |
| `drip` | `col`, `top`, `bottom`, `period=40`, `phase=0`, `over=" "`, `color` | A drop falls down a column, then rings spread at `bottom` |

## Style rules (from Galata)

1. **Canvas 96 x 26.** Everything fits in a 100 x 30 terminal with the label line. Leave the right or left
   third calmer, so the scene reads as a composition and not wallpaper.
2. **Printable ASCII only.** Box-drawing and block characters differ in width and look across fonts and
   platforms.
3. **Line art with filled masses.** Outlines use `/ \ | _ = [ ] ( ) ^ n o`. The large masses (tower
   body, dome, hull) get a fill key, so they read as solid shapes against the gradient sky.
4. **Recognisable at a glance.** Get the landmark's defining silhouette right first: Galata's pointed cone
   and arcaded balcony, Ayasofya's wide dome with its minarets, the bridge's two towers and cable sag.
   Detail comes second.
5. **Context tells the story.** Galata sits up the hill behind houses, with a ferry on the Golden Horn.
   Every scene should say *Istanbul*: water, gulls, ferries, rooftops, minarets on the skyline.
6. **Four palettes that each work.** Morning is soft and pale, day is clear blue, sunset is purple to
   orange, night is deep blue with lit windows and stars. Check every one.
7. **Animation is visible but calm.** Something should move within a second of looking (waves, gulls,
   smoke, lights), and nothing should flash or strobe.

## Workflow

```sh
python3 tools/scene-preview.py <name> --check   # validates keys against palettes, renders frames headless
python3 tools/scene-preview.py <name> --plain   # the raw art
python3 tools/scene-preview.py <name> --cycle   # live, in a real terminal (Ghostty etc.)
python3 tools/scene-preview.py <name> --png out.png [--frame N]   # all four palettes stacked, crude glyphs
```

A scene ships once a human has watched it with `--cycle` and approved it.
